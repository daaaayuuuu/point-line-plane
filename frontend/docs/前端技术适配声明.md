# 前端技术适配声明

## 依据

本前端只按以下输入实现：

1. `AI产品工厂Agent中台_PRD_V0.1.md`
2. `AI产品Vibe Coding通用前端技术栈手册.md`
3. 本地 `DESIGN.md`、`theme.css`、`tokens.json`、`variables.css` 中的 Relate 视觉与组件规范
4. 八个独立后端阶段当前实际开放的 API 契约

外部设计页面只作为视觉规范参考，不复制其品牌、Logo、文案或产品资产。

## 技术选择

- React 19 + TypeScript 严格模式
- vinext（Next.js App Router 兼容运行时）
- 集中的 API 客户端：`lib/api/client.ts`
- 集中的接口类型：`lib/api/types.ts`
- Lucide 图标，不使用 Emoji 充当功能图标
- Tailwind CSS 4 + 独立 `app/design-tokens.css` 语义设计令牌 + 原生 CSS 响应式布局

## 视觉适配

- 中文字体使用 Geist/Inter 思路与苹方、微软雅黑、Noto Sans CJK 系统回退，不打包缺少中文字形的商业字体。
- 正文最小 14px，辅助信息使用 12px；显示标题按 40/56/80px 层级自适应，不使用 8–11px 正文。
- 页面最大内容宽度 1200px，桌面侧栏 296px；颜色、圆角、阴影和焦点状态均来自统一设计令牌。
- 桌面检查 1280px/1440px，移动检查 390px/768px；移动侧栏使用抽屉，触控目标不小于 44px。

页面不在浏览器存储邀请码、模型 Key、云凭证或运维令牌。登录状态由后端 HttpOnly Cookie 管理；所有业务数据和任务状态以后端为唯一事实来源。

## 交互策略

- 面向普通用户：先显示结果、风险和下一步，再展示技术细节。
- 技术内容不改写成伪概念：代码、Git、HTTPS、Token、数据库等名称保持准确，并配普通语言解释。
- 长任务采用轮询恢复，不用前端假进度。
- 失败状态保留后端错误码与追踪信息，并给出可执行的恢复动作。
- 项目和阶段写入 URL 查询参数，刷新页面后可以恢复入口；业务进度仍由后端恢复。

## 当前边界

- 本地联调使用第八阶段累计后端 `http://localhost:8018/api/v1`。
- 正式云部署默认关闭时，前端会如实显示“部署未启用”，不会伪造线上地址。
- 生产环境必须单独配置 HTTPS 后端、强随机密钥、PostgreSQL、真实模型与受审计的部署适配器。
